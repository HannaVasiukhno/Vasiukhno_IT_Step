# My Python Project

Невеликий навчальний проєкт на Python для практики роботи з кодом, віртуальним середовищем та системою контролю версій Git.

## Опис

Проєкт призначений для відпрацювання базових навичок розробки:
- структурування коду;
- робота з бібліотеками (наприклад, `pandas`);
- фіксація змін та відправлення репозиторію на GitHub.
